# 打斗提示词三层流水线

最终交付只有一份可复制提示词。三层是内部工序，不要把三份半成品都交给用户。

用户给出的规则，按原意执行：

第一层：用 fight-scene-director 做空间和镜头规划。输入角色、武器、场景，拿到站位关系和镜头序列。这一步决定“谁在左、谁在右、这一镜拍什么”。

第二层：把每一镜的“交锋点”交给 h3-combat-impact 做打击强化。比如 fight-scene-director 输出“第 3 镜：A 从左侧突进劈砍”，你把这一句喂给 h3-combat-impact 的六拍模板，生成带蓄力、顿帧、力场反馈的完整提示词。

第三层：用 fight-prompt-director 的连续性规则做校验。检查相邻镜头的朝向、武器位置、场景损伤是否一致，不一致就打回第一层调整。

开始前先读本文件，再只读当前层需要的参考，不要三份 SKILL 同时全文灌入。

## 开始前先定的三件事

已给出的不要再问。缺了才用默认值：

- 模型：Seedance。用户点名 H3、海螺、Hailuo 时改用 MiniMax H3。
- 时长：Seedance 15 秒；H3 单段 8 秒，超过 15 秒再切段。
- 画幅：16:9。

速度档位只在用户说过极速、再快、标准、正常时采用。没说就按标准版，不要为了速度再问一轮。

## 第一层：空间和镜头

读 [fight-scene-director/SKILL.md](../fight-scene-director/SKILL.md)，以及它指向的 `choreography-and-camera.md`、`output-format.md`。这一层只规划，不写打击特效，不产出可粘贴成片提示词。

输入是角色、武器、场景。输出一张内部调度卡：

```text
【第0秒站位】
屏幕左：角色、朝向、武器（哪只手、角度、数量）
屏幕右：角色、朝向、武器（哪只手、角度、数量）
距离、高低、场景里还完好的锚点

【镜头序列】
镜1｜0-2秒｜景别与运镜｜这一镜只拍：空间关系
交锋点：无
切出：左右、朝向、武器、场景损伤

镜3｜4-6秒｜景别与运镜｜这一镜只拍：劈砍接触
交锋点：A从左侧突进劈砍
切出：左右、朝向、武器、新增的场景损伤
```

约束：

- 每一镜只有一个观看任务：空间关系、单人、细节，或动作结果。
- 交锋点是一句因果，写清谁发起、从哪一侧、打向哪里、接触还是格挡还是落空、对方因此移到哪里。不写蓄力、顿帧、爆白、力场。
- 没有接触、也没有受力结果的镜头，交锋点写“无”。
- 第 0 秒只写已经存在的站位，不写后续动作。
- 时间首尾相接，覆盖完整时长，不重叠。

## 第二层：交锋点打击强化

只对交锋点不是“无”的镜头，读 [h3-combat-impact/SKILL.md](../h3-combat-impact/SKILL.md) 的六拍、力场四通道，以及 `references/impact-design.md`。不要重排左右，不要增删镜头，不要改谁发起。

把第一层那一句原样作为输入。例如“第 3 镜：A 从左侧突进劈砍”，展开成六拍，并写回该镜：

| 拍 | 占比 | 这一镜必须看见 |
|---|---|---|
| 蓄 | 35% | 反向预备、重心后沉、武器绷紧 |
| 触 | 5% | 接触点；冲击帧写成两帧 |
| 停 | 15% | 近乎冻结，尘土或火花停在空中 |
| 泄 | 25% | 力场，最多三个通道 |
| 退 | 15% | 受力位移，衣料或头发滞后，震屏在三分之一秒内衰减 |
| 收 | 5% | 回到可接下一镜的姿势，残留粒子还在 |

力场优先级：空气、物质、光、粒子。一次最多开三个通道。一击只有一个视觉高潮。

节拍选择：

- 这一镜是一次有蓄力的重击：用六拍。这是默认。
- 第一层已经把这一镜写成压着打、没有停顿余地：改读 `references/continuous-brawl.md` 的四拍，不写冻结。不要在同一镜里混用六拍和四拍。
- 用户没有明确要求超高速跟拍时，不用 ULTRA_SPEED，也不要把一镜拆成十镜以上。

无交锋点的镜头保持第一层的景别、运镜和切出状态，不补打击词。

组装：

- Seedance：用 fight-scene-director 的中文两行镜头格式。六拍写进该镜的正文段落。`【参考资产】` 留空。提示词后可以附节奏面板，面板不属于提示词。
- MiniMax H3：用官方三字段英文提示词，时间码沿用第一层。`[Shot 1]` 不写时间码。否定句改成正面约束。交付前按该 skill 的格式检查；有 `scripts/validate_prompt.py` 就跑它。

字数不够时删形容词，不删动作，不删左右和武器状态。重要的朝向、武器、损伤约束放在对应镜头前部。

## 第三层：连续性校验

读 [fight-prompt-director/references/camera-guide.md](../fight-prompt-director/references/camera-guide.md) 的「连续性记录」，以及 [diagnostics.md](../fight-prompt-director/references/diagnostics.md) 里和左右、武器、损伤有关的条目。这一层不重写提示词，不输出第二套强度方案。

逐对检查相邻镜头的切出和切入：

1. 朝向：屏幕左和屏幕右没有对调；面朝方向能从上一镜的运动接上。越过轴线必须在第一层就写明机位绕到了另一侧。
2. 武器位置：数量、持手、角度连续。刀不能换手、不能变两把、不能在切镜后回到入鞘。
3. 场景损伤：裂开、折断、倒塌、留下的碎片必须出现在后面的镜头里。损伤不能自己愈合，也不能无接触就出现。

任一项失败就打回第一层，格式固定：

```text
打回第一层
镜3→镜4：武器。镜3切出右手持刀下劈，镜4开场刀在左手。
只改这一处站位或机位。已通过的交锋点不要重写。
```

第一层只改被点名的衔接，第二层只重做交锋句变了的镜头，然后重新校验。同一处打回两次仍不一致，退回第一层重排这一镜的机位，不要在第三层里直接改句子。

三项都通过才交付。

## 交付

交给用户的是通过校验的那一份提示词。用一两句说明模型、时长、画幅。若发生过打回，用一句话说明改了哪一镜的哪一项。不要附调度卡、六拍草稿和校验表，除非用户明确要看工序。
